# Os números não batem

Uma fonte única de verdade para o funil de crescimento da Olist: lead, contrato, primeira venda e receita.

Na reunião do mês, marketing, vendas e financeiro trazem números diferentes para a mesma pergunta. Este projeto reproduz essa divergência com os dados reais da Olist, mede o tamanho de cada causa e constrói uma camada única de métricas em dbt que impede a divergência de voltar.
